# adresscore

Jakość życia pod każdym adresem w Polsce: heatmapa kraju, lot do miasta w 3D i etykieta adresu
A–G złożona z rejestrów publicznych.

```
pnpm install
cp .env.example .env.local   # klucze Supabase
pnpm dev                     # http://localhost:5180
pnpm verify
```

Koncepcja: [docs/koncepcja.md](docs/koncepcja.md).
